# 블러 에디터

사진·동영상에 블러 처리와 간단한 편집(손글씨 텍스트, 크롭)을 해서 인스타/스레드 업로드용으로 빠르게 내보내는 개인용 PWA. 기획은 [blur-app-spec.md](blur-app-spec.md) 참고.

## 개발 서버 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 (안드로이드/맥/아이패드에서 테스트하려면 `npm run dev -- --host` 로 같은 와이파이 기기에서 접속).

## 빌드

```bash
npm run build
npm run preview
```

`dist/` 폴더에 정적 파일이 생성됩니다 (서비스워커·매니페스트 포함).

## 배포 (URL 공유)

스토어 등록 없이 URL 공유만으로 충분합니다. `dist/` 폴더를 아무 정적 호스팅에 올리면 됩니다 — 예: Vercel, Netlify, Cloudflare Pages, GitHub Pages. HTTPS가 필요합니다(PWA 설치·서비스워커 요구사항).

```bash
# 예: Vercel
npx vercel --prod

# 예: Netlify
npx netlify deploy --prod --dir=dist
```

배포된 URL을 아이패드/안드로이드 사파리·크롬에서 열고 "홈 화면에 추가"하면 앱처럼 아이콘으로 설치됩니다.

## 구현된 기능

- **사진**: 손가락으로 그리는 자유 곡선 블러, 손글씨 텍스트(구글 폰트: 나눔손글씨 펜/개구쟁이/나눔손글씨 붓/Caveat/Kalam), 크롭(자유+1:1/4:5/9:16 프리셋), 90도 회전
- **동영상**: 특정 프레임에서 원형/사각형 블러 영역을 지정하고 시작~종료 시간 구간을 설정하면, 내보내기 시 실제 픽셀에 구워서(re-encode) 저장. 크롭/회전도 지원
- **자동 저장**: 편집 상태를 IndexedDB에 자동 저장, 앱을 껐다 켜도 이어서 작업 가능
- **홈 화면**: 작업 목록(썸네일), 관리 모드로 개별/다중 삭제
- **내보내기**: 사진첩(다운로드) 저장, Web Share API 지원 기기에서는 바로 공유
- **오프라인**: 서비스워커가 앱 셸과 폰트를 캐시해 편집 기능은 오프라인에서도 동작 (업로드/공유만 인터넷 필요)

## 알아두면 좋은 점

- 동영상 블러 굽기는 `HTMLVideoElement.captureStream()` + `MediaRecorder`로 실시간 재생하며 재인코딩하므로, 영상 길이만큼 처리 시간이 걸립니다. 오래된 브라우저에서는 미지원일 수 있어요(최신 Chrome/Safari 권장).
- 동영상 편집에는 손글씨 텍스트를 넣지 않았습니다(기획서상 핵심 기능인 고정 위치 블러 + 시간 구간에 집중). 필요하면 이어서 추가할 수 있는 구조입니다.
